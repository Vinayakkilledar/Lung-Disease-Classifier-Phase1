# Lung Pulmonary Disease Detection & Classification

This project aims to develop a deep learning-based system for classifying chest X-ray images into three categories:

- Normal
- Lung Opacity
- Viral Pneumonia

## Current Project Status

Approximately **25% of the project** has been completed as of **22 August 2026**.

### Completed Work

- Project topic finalization
- Problem statement and objectives
- Literature survey
- Requirement analysis
- Dataset study and organization
- Study of image preprocessing techniques
- Basic image loading, resizing, and normalization
- Study of CNN architecture
- Initial CNN model structure
- Basic system architecture planning

## Technologies Used

- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib

## Current Repository Scope

This Phase-1 repository contains only the early-stage project work. Model training, performance evaluation, Flask integration, frontend development, and final testing are intentionally kept for later phases.
